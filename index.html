🎂 2-DAY GAME PLAN (Evidence-Based)

Saturday - USF Focus (rope drop Diagon Alley): Gringotts first (lowest morning waits historically). Leaky Cauldron for birthday lunch (themed, mobile order, free treat). Minions, shows. Cooler snacks all day.

Sunday - IOA Focus: Hogsmeade early, Forbidden Journey, Mythos Restaurant for special birthday meal (top rated, aquarium, kid-friendly, $25-45). Jurassic area.

Mornings = 30-50% shorter waits. PM rain common in Oct → indoor pivot (Wizarding World, Mummy). Use official Universal app for live waits + mobile order. HHN evenings = busier/scarier for 9yo — focus days.

Key Tips

  • App first: Universal Orlando app for live waits, mobile order, map, menus.
  • Birthday: Guest Services button + mention at Leaky/Mythos for free treat.
  • Cheapest: Cooler permitted. QS value meals. Avoid multiple table service.
  • Waits: Mornings best (historical data). Single rider lines. themeparks.wiki for public data.
  • Weather: Flexible plan. Rain = shorter lines but indoor focus (Harry Potter, shows).
  • HHN: October = Horror Nights. Daytime focus for 9yo.
